## AI providers

Two providers: `opencode` (OpenCode Go — opencode.ai/docs/go, a flat-fee subscription giving OpenAI-compatible `chat.completions` access to open-source models like GLM/DeepSeek/Kimi; only the `/v1/chat/completions`-shaped model group is wired, not the Responses- or Anthropic-shaped groups Go also offers) and `google` (native Gemini SDK). **The AI is provided by the platform** (since S4, 2026-09-25): one key per provider, configured from `/plataforma` and stored encrypted in `PlatformSettings` (`opencodeApiKey`/`googleApiKey`, `lib/ai/platform.ts:getPlatformApiKey()` — async since S5, 2026-09-28, reads through `lib/platform-settings.ts`); customers never configure keys. A provider without a key simply isn't offered. **Models are curated and assigned by the platform**: `lib/billing/plans.ts:AI_MODELS`; clients do not choose a provider/model. Creates use `pickCuratedModel()` and updates silently reassign a saved model if its provider has been disabled. **The operator picks the actual model** (2026-10-27) in `/plataforma` → Configuración → "Inteligencia artificial": `PlatformSettings.aiTextModel` / `aiVisionModel` (empty = the recommended one). The selectors are fed by the live OpenCode catalog (`GET /api/plataforma/configuracion/modelos` → `fetchOpenCodeModelCatalog()`, 5 min cache, fallback to `AI_MODELS` when OpenCode doesn't answer); `PATCH /api/plataforma/configuracion` validates the ids against that catalog (or at least rejects `gemini-*` when the catalog is unreachable). `lib/ai/platform.ts:resolvePlatformModel()` is the resolution order: audio → Gemini (OpenCode has no audio input), otherwise OpenCode with the chosen text/vision id, Gemini only when no OpenCode key exists; `normalizeOpenCodeModel()` drops a Gemini-shaped id to the recommended OpenCode model so a bad saved value can't break every reply. Migration `20260928162208_migrate_openrouter_models` converts existing OpenRouter bot/scorer rows to supported Gemini or OpenCode models while preserving Gemini audio support where possible. **Credits** (`lib/ai/credits.ts`): 1 credit = 1 AI call (bot reply, suggestion, score, recovery message, automation AI step; embeddings don't count). `reserveAiCredit(orgId)` is an atomic capped increment done **after** confirming a platform key and **before** the call (concurrent calls can't pass the cap); `hasAiCredits()` is the cheap pre-check for ticks. 80 %/100 % notices once per period (`aiCreditsAlertLevel`); the period resets on each paid Stripe invoice (`subscription_cycle`/`subscription_create`, amount > 0) or, without a subscription, one month after the last reset. Out of credits: bots stay silent (no ERROR), AI steps take their "otro" branch, manual actions answer 402 `ai_credits`.

Provider clients in `lib/ai/providers/`. Factory in `lib/ai/factory.ts`.

- **Multimodal in/out**: `AIMessage.content` is `string | ContentPart[]` where `ContentPart` is `{type:"text",text}`, `{type:"image_url",image_url:{url}}` or `{type:"audio_url",audio_url:{url}}`. Both providers forward arrays natively. The Google provider maps `image_url`/`audio_url` with a `data:` URI base64 into `inlineData: {mimeType, data}`; plain URLs (non-data-URI) are NOT supported inside inlineData — bot-worker always builds data-URI from local bytes. **Audio input is Gemini-only** (`bot-worker.ts` gates `isAudio` on `provider === "google"`; OpenAI's chat shape has no generic audio part). **Documents** (PDF/`text/*`) are provider-agnostic: `lib/whatsapp/extract-document-text.ts` extracts text server-side (max 6000 chars) and injects it as a plain text part. Bot reply stays text-only (media input, no media output).
- **Embeddings are Google-only**: OpenCode Go has no embeddings endpoint at all. `lib/ai/embeddings.ts:resolveEmbeddingProvider()` silently swaps `opencode` for `google` before generating any embedding — a bot that *replies* via OpenCode still needs Google's API key configured in `/plataforma` for its RAG to work, and throws a clear error if that key is missing. Dimension is 768 (Google `gemini-embedding-2`, truncated via `outputDimensionality` — see `lib/ai/providers/google.ts`).
- **Google usage**: `usageMetadata` on `response` object provides `promptTokenCount`, `candidatesTokenCount`. Must be returned in `AICompletionResponse.usage`.
- **Google `systemInstruction` gotcha**: must be passed to `genAI.getGenerativeModel({ model, systemInstruction })`, never to `.startChat({ systemInstruction })`. The SDK (`@google/generative-ai`) only runs its string→`Content` formatting on the value passed to `getGenerativeModel`; passing it to `startChat` instead silently overrides the formatted value with the raw unformatted one and the REST API rejects it with a 400 on `system_instruction`. **Caveat**: only a `string` `systemInstruction` is supported by the v1 SDK path — if you pass it parts/array, the formatter will mangle it. Always send a plain string for the system prompt even when the rest of the conversation is multimodal. The provider **concatenates all `system`-role messages** (`join("\n\n")`) into that single `systemInstruction` — the pipeline sends several (wrapped user prompt, RAG context, guardrail, campaign note) and an earlier version silently dropped all but the first.
- Model pricing in `lib/ai/pricing.ts` (USD per 1M tokens, static table, no live pricing API for either provider). **OpenCode Go is a flat $10/mo subscription, not billed per token** — its curated models are entered at `{input: 0, output: 0}` on purpose, so the dashboard doesn't show a misleading per-token cost; the real subscription cost isn't prorated per call. **Google has no pricing API either** — its entries are hand-maintained (last verified 2026-07-15); a model missing from the table logs cost $0 with a console warning, so add pricing when adopting a new Gemini model or `WABotUsage.estimatedCost`/the budget silently undercount. Usage logged per interaction in `WABotUsage`.
- `GET /api/configuracion/ia/models?provider=` returns the curated models of an enabled provider (without `provider`: `{providers, models}`); the bot/scorer forms fall back to `AI_MODELS` if the fetch fails.
- RAG: documents chunked → embeddings generated (always via Google, see above) → stored in pgvector → searched with cosine similarity (`<=>` operator).
- **Vision model cost**: each image in context ≈ +800-1500 tokens. Bot history is text-only (no past images forwarded); only the *current* user image becomes an `image_url` part in the `user` turn. The worker re-reads `WAMessage.mediaUrl` from DB if the Meta download job hasn't finished populating the local path yet.
- **Vision capability check**: there's no enforced gate on per-model vision capability — if a model isn't vision-capable it will error on the multimodal turn, which the bot-worker catch sets `WABot.status: "ERROR"` (same as any other AI failure). Currently known vision-capable models: Gemini 1.5/2.0 Flash/Pro, OpenCode Go `deepseek-v4-flash-vision-exp` (the only vision model in Go's chat/completions group).
- **Lead scorer bots** (`WALeadScorerBot`) reuse the same provider/model/API-key plumbing as `WABot` (own `provider`+`model`+`systemPrompt`, resolved via the same `getPlatformApiKey()`) but score a conversation on demand instead of replying to it — see "Lead scoring" under CRM below.
- **User-configured system prompts are wrapped, not sent raw**: `lib/ai/prompt-sanitizer.ts:wrapUserPrompt()` frames both `WABot.systemPrompt` (`bot-worker.ts`) and `WALeadScorerBot.systemPrompt` (`score/route.ts`) inside a delimited `<user_instructions>` block with an explicit "treat as data, not instructions" preamble and a length cap — mitigates prompt injection against the system messages that follow (RAG context, memory summary, the scorer's JSON contract). The scorer's JSON contract also now asks for a fenced ` ```json ` block; `parseScoreResponse()` tries that first and falls back to the old greedy `{...}` regex for models that ignore the fencing instruction. `prompt-sanitizer.ts` also exports `SCOPE_GUARDRAIL` — a fixed system message (priority over `<user_instructions>` and any user/media content) appended by `bot-worker.ts` and `lib/whatsapp/lead-recovery.ts`; include it in any new AI flow that converses with end users.
- **Model list race on provider switch**: `configuracion/ia/page.tsx` and `bots/_form.tsx` both track a `modelsProvider` state alongside the fetched `models` list, and only snap the selected model to `models[0].id` once `modelsProvider` matches the currently selected `provider`. Fetching the model list is async — without this guard, switching OpenCode→Google right after load/save could persist an OpenCode-shaped model id under the Google provider.

## Uso de IA de asistencia (`AiAssistUsage`, 2026-11-01)

Las llamadas que ayudan al equipo y no responden al cliente —reescribir un borrador (`REWRITE`), proponer una tarea (`TASK`), transcribir una nota de voz (`TRANSCRIBE`), monitores de temas (`MONITOR`)— registran su costo en `AiAssistUsage` con `lib/ai/assist-usage.ts:recordAssistUsage()`, que nunca lanza. `getOrgAiCost()` la suma junto a bots, calificadores, recuperación y automatizaciones. Una llamada nueva de este tipo: `getPlatformApiKey` → `reserveAiCredit` → proveedor → `recordAssistUsage` con su `kind` (agrega el valor al enum si hace falta). `suggest-reply` sigue registrándose en `WABotUsage` porque usa el bot de la cuenta.

## Transcripción de notas de voz (2026-11-01)

`lib/ai/transcribe.ts:transcribeMessage(kind, messageId)` convierte un audio (`WAMessage` o `ChannelMessage`, `messageType: "audio"`) en texto y lo guarda en `transcript`/`transcribedAt`. Solo Gemini entiende audio: `resolvePlatformModel({ needsAudio: true })` debe devolver `google`, si no responde `unavailable` (503) — en dev sin llave de Google es lo esperado. Orden: modelo → llave → `hasAiAccess` → tamaño del archivo (tope `TRANSCRIBE_MAX_BYTES`, 18 MB, antes de gastar) → `reserveAiCredit` → Gemini (temperatura 0) → guardar → `recordAssistUsage(TRANSCRIBE)`. Un mensaje ya transcrito devuelve el texto sin gastar crédito. Manual: `POST /api/whatsapp/messages/[messageId]/transcribe` (mismo alcance que el proxy de medios, busca en las dos tablas, 20/min por usuario, 402 `ai_credits`/`plan_limit`). Automático: `Organization.autoTranscribeAudio` (apagado por defecto, interruptor en `/configuracion/ia`); `media-worker` llama `queueAutoTranscribe()` al guardar un audio INBOUND, que solo encola `inbox/transcribe` si la organización puede escribir y tiene créditos. Tests de orden de puertas en `lib/ai/__tests__/transcribe.test.ts`.
