PARTE A · ARREGLOS Y DISEÑO

CONTEXTO
Hicimos una revisión de QA funcional y de diseño de app.colibly.com. La conclusión: el producto funciona y el sistema de diseño tiene buena base (tokens semánticos, contraste probado, foco accesible), pero se ve "hecho por IA" por decisiones de kit acumuladas: paleta de Tailwind (cyan-700), neutros de dos temperaturas, tarjetas KPI idénticas con etiquetas en MAYÚSCULAS, estados vacíos con ícono en cuadro teal, animaciones de entrada escalonadas, subtítulos de relleno, menú de 22 entradas y banner azul de prueba en todas las pantallas. Además hubo 5 paletas en 3 semanas.

La dirección es: CONGELAR LA MARCA Y PULIR EL OFICIO. Se queda el teal como único acento, se queda Barlow (Barlow Condensed solo para cifras), se queda la franja de color por cuenta y la espera como dato protagonista. NO propongas otra paleta, otra fuente ni otra metáfora visual.

REGLAS GENERALES
- Antes de empezar, lee AGENTS.md, CLAUDE.md, app/globals.css, app/layout.tsx, .impeccable/design.json y docs/arquitectura/frontend.md. Los números de línea de este prompt vienen de un snapshot anterior (commit bada0cf); verifica rutas y líneas en el código actual antes de editar.
- No agregues dependencias nuevas. Si alguna es indispensable, justifícalo en el mensaje de commit y en el CHANGELOG.
- No cambies lógica de negocio, APIs, esquemas de Prisma ni permisos salvo donde la fase lo pide explícitamente (QA-018, QA-020, validaciones).
- Al final de CADA fase: npm run lint, npm run typecheck (o tsc --noEmit), npm test y npm run build deben pasar en verde. Si algo ya fallaba antes de tu cambio, dilo en el resumen; no lo escondas.
- Un commit por fase (puedes hacer commits intermedios dentro de la fase si te ayuda, pero cierra cada fase con un commit "fase N: ..."), en español, y push a main al cerrar cada fase.
- No toques secretos, variables de entorno de despliegue, Coolify ni credenciales. No hagas deploy manual. No imprimas tokens en logs.
- Textos de la UI en español de México, tuteo, sin signos de admiración, sin "¡Empieza ahora!". Vocabulario fijo: Chats, Contactos, Embudo, Etapa, Venta ganada / perdida, Asignado a, Canal, Número. No mezcles "lead" y "contacto" en la UI (usa "contacto"; "trato" para la tarjeta del embudo).
- Respeta prefers-reduced-motion y mantén el foco visible.
